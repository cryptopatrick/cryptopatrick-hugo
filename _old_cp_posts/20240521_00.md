## Background
The __Finite Element Method (FEM)__ is a __Numerical Method__ for solving problems in
engineering and mathematical physics. In contrast to __Analytical solutions__, which provide mathematical expressions that yield values at any location in a structure,
FEM results in a system of algebraic equations for a discrete number of points in the structure.

The main reason why FEM has become so popular is because of the rise of popularity of the computer. Until early 1950s, matrix methods and FEM was available but extremely cumbersome to to by hand. The advent of the computer changed all this, making it possible to find the solution of thousands of equations in a matter of minutes.

## FEM: General Steps
Structural: Springs, Bars, Beams, Plane frames, Plane stresses
Nonstructural: Heat transfer, Fluid flow

Two general approaches:  
1) Flexibility Method : internal forces are the unknowns of the problem
2) Stiffness Method : displacements of nodes are the unknowns of the problem

> For computational purposes, the Stiffness Method is to be preferred.

The idea is to _model_ the structure, let's say an iron beam, using _finite elements (small interconnected elements)__.
A _displacement function_ is associated with each finite element.
The elements are interconnected, directly or indirectly, to every other element in the structure - through _nodes_, and/or _boundary lines_, and/or _surfaces_.

> There are 7 steps in FEM but only the first step needs involvement from the analyst, the remaining 2-7 steps are carried out automatically by a computer program. 

### Step 1: Discretization and Select the Element Types
Our _first_ task is __discretization__, that is - to divide the structure, let's say a steal beam, into a _system of finite elements with associated nodes_.
The higher the __number of elements__, the smaller they must be, but that also means a more computationally heavy task.

_Next_, we need to select an appropriate _element type_ to model most closely the structure's physical behaviour
We also need to decide if we're going to use:
+ __1D__ Line element (2 nodes) for a bar, truss, and beam.  
+ __2D__ : Plane element often represented as triangle (3 nodes) or quadrilateral (4 nodes) elements
+ __3D__ : The most common three-dimensional element types   
are Tetrahedral (4 nodes) and hexahedral (brick with 8 nodes)

> 1D line elements are the simplest type and should be mastered first to understand the basic concepts of FEM.

### Step 2: Select a Displacement Function
Using the _nodal values_ of each element, we choose a displacement function for each element. Popular displacement functions include:
linear, quadratic, cubic, and trigonometric.

For a 2D element (let's say a triangle), the displacement function of an element is a function of its coordinates in the xy-plane.
