## Crate: [radar](https://crates.io/crates/radar)
1. __Description__  

> STANAG 4607 defines Ground Moving Target Indicator (GMTI)

I created this project to demonstrate my ability to 1) work with _radar data_ and 2) create user-friendly _visualizations_ (which are an important part of radar systems).
A simple radar data visualization tool takes simulated radar data and visualizes it using libraries like Matplotlib or Plotly.
The application generates synthetic radar data points, such as these...

```scala
struct Datapoint {
  range
  azimuth
  speed
}
```
2. __Features__  
__•__ _Visualization_: We use the excellent <REF> Matplotlib, and its 2D library, to plot and represent radar signatures.  
__•__ _HMI Controls_: The following actions are available to the user: _filter_, _zoom into and out of data points_, and _mark data points_.
<br>
<br>
3. __Technologies__  
Python, Matplotlib/Plotly, NumPy
The application Implements a simple signal generation (e.g., chirp signal).
4. __Resources__

## 2. App: CFAR
1. __Description__  
This application creates a simulation of a basic _radar signal processing chain_
, including signal generation, filtering, and detection algorithms.
Using the _radar_ crate we generate synthetic radar signals that are then fed
into our REF CFAR detection application. 
This project illustrates our understanding of _radar signal processing principles_ 
and our ability to implement _algorithms_ relevant to radar systems.
<br>
<br>
2. __Features__  
__•__ _Synthetic Radar Signal:_ the crate _radar_ is used for simple signal generation (e.g., chirp signal).   
__•__  _Digital Filters:_ A few digital filters can be applied to simulate noice reduction.  
  These are the filters: low-pass, high-pass  
__•__ _Detection algorithms:_ (e.g., CFAR) to identify targets.
<br>
<br>
3. __Technologies__  
Python, NumPy, SciPy

## 3. Algorithm: Radar Object Detection in Rust
1. __Description__  
I created this application in order to practice low-level programming and algorithm implementation, an important skill for _real-time radar processing_.
The application is written in C, implementing a _radar object detection_ algorithm, based on real LINK _radar principles_. A user interface, written in PyQT++ makes it possible
to view the result of the application.
<br>
<br>
2. __Features__  
__•__ _Synthetic Radar Signals_Input radar returns (simulated or from a dataset).
__•__ _Detection algorithm:_ we implement two algorithms: matched filtering and Kalman filtering.
__•__ _Output:_ Any "detected" radar objects, and their characteristics (e.g., position, velocity) range_azimuth_speed, are output to the user interface.
<br>
<br>
3. __Technologies__
Linux, C, OpenCV for visualization, PyQT++ for GUI.

## 4. CLI: Radar System Configuration Tool
1. __Description__  
I don't have a military radar in my backyard, but I wanted to get a sense of
what it means to service and configure a radar. This project was created with the hopes of showing my ability to develop a user-centric application, enabling the user to _configure a model of a complex, radar system_.
I decided to build a small CLI (Command Line Interface) tool that would allow users to configure radar parameters and save/load configurations for different scenarios.
{{<indentline>}}The user can login to the radar server, once authenticated, the user can either directly
configure radar parameters, or load parameters from a file, or download parameters to a file. The user can also get a history log of a all the users that have logged in and what actions they performed while logged in (there's even an intrusion detection daemon running to try and protect the radar in case actions are deemed to be outliers). 
<br>
<br>
2. __Features__  
__•__ CLI with login and authentication.  
__•__ Radar configuration commands for e.g., frequency, power, pulse width.   
__•__ Save or load radar configurations to/from JSON or XML files.  
__•__ View history log of changes and who made them.  
__•__ Validate configurations before simulation.
<br>
<br>
3. __Technologies__  
Python (Tkinter or PyQt) or Java (JavaFX), and JSON/XML

## 5. Multi-threaded Radar Processing Framework
1. __Description__  
Real-time processing and streaming services was something I wanted to explore.
So I created an application.
Using a multi-threaded framework in C++ for processing radar signals in real-time, I also simulate various radar tasks, like _tracking_, _detection_, and _visualization_.
<br>
<br>
2. __Features__  
__•__ _Threads:_ are used to handle different radar tasks concurrently.
Concurrent tasks include data acquisition, signal processing, visualizattion.  
__•__ _Pipeline architecture_: used to process radar signals in stages.  
__•__ _Error handling_: for robustness, proper error handling and logging is done.
<br>
<br>
3. __Technologies__  
Rust or C++, pthreads (for multi-threading), Linux
