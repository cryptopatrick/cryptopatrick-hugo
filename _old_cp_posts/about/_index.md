

# Everydays

> Inspired by Beeple (Mike Winkelmann) [Everyday project](https://www.theatlantic.com/video/archive/2011/10/creativity-is-hustle-make-something-every-day/246377/#slide15), the mini code projects on my website are all done from start to finish in one day. The main goal of doing _Everydays_ is to help me get better at software develpment, build muscle memory, and become quicker at what I do. By posting the results online, I'm "less" likely to throw down a big pile of crap (even though most of the time I still do, because I suck :D ).

# Round 01
> I am currently on my __1st round of Everydays__. This year I'll be coding a small application everyday using mainly `Rust` and mostly `React`, instead of trying to learn new shiny framework, I will be focusing on three fundamentals of software development, like: __1.__ Problem-Solving and Design (Requirement Analysis, System Design, Algorithms and Data Structures), __2.__ Coding and Implementation (Programming Languages: Proficiency in two programming languages, Code Quality, Version Control), and __3.__ Testing and Iteration (Testing, Debugging, CI/CD).
