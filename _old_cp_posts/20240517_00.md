## Background
The __Finite Element Method (FEM)__ is a __Numerical Method__ for solving problems in
engineering and mathematical physics. In contrast to __Analytical solutions__, which provide mathematical expressions that yield values at any location in a structure,
FEM results in a system of algebraic equations for a discrete number of points in the structure.

The main reason why FEM has become so popular is because of the rise of popularity of the computer. Until early 1950s, matrix methods and FEM was available but extremely cumbersome to to by hand. The advent of the computer changed all this, making it possible to find the solution of thousands of equations in a matter of minutes.

## Transformation Matrix $G$
> Explain: How the transformational matrix G will be used.

We need to know the __length of the beam__. This is calculated with:
$$
L = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}
$$

```scala

```

The tranformation matrix, $G$, contains __the direciton cosines__:

$$
n_{x\bar{x}} = n_{y\bar{y}} = {{x_2 - x_1} \over L } \quad \quad \quad n_{y\bar{x}} = - n_{x\bar{y}} = {{y_2 - y_1} \over L }
$$

  0 & 0 & 1 & 0 & 0 & 0 \\\

$$
