also to practice using the math I'm learning to model stuff to understand how things might fit together.

## Model Components and Variables

1.Search Radar Detection (10 km range)

- Drones are detected at a distance of up to
  $R_\text{search} = 10km$.
- The system can track and prioritize multiple drones simultaneously.

2. Engagement Range (4 km)

- The gun system engages drones when they come within
  $R_\text{engage} = 4km$.

3. Number of Cannons in a Battery

- For $50$ drones, at least $N_\text{cannons} = 7$.

4. Gun Performance

- The cannon can intercept up to
  $N_\text{drones} = 8$ small drones within a few seconds.
- Each cannon has a capacity of
  $C_\text{rounds} = 250$ rounds
- The system uses proximity ammo, reducing the need for direct hits.
  Let's assume $N_\text{rounds} = 5$ rounds are used per drone on average.

5. Drone Characteristics

- Drones travel at speed $v_\text{drone}$ in $m/s$ which will vary depending on the type of drone.
- There could be up to $50$ drones approaching, with a spacing of
  $d_\text{drone}$ between them (either as a swarm or spread out).

6. Radar and Sensor Performance

- The system employs radar, TV-tracking, IR-tracking, and a laser range finder, making jamming or evasion by drones extremely unlikely.
- Let's assume the radar can handle simultaneous tracking of
  $N_\text{radar} = 100$ drones.

7. Engagement Timing

- Engagement is automatic, based on prioritization by speed and course.
- Reaction time $t_\text{reaction}$ between detection and engagement is determined by sensor processing and mechanical limitations of the gun.

## Equations

### Time to Engagement

The time for a drone to move from radar detection range to engagement range is given by:
$$t_\text{engage} = \frac{R_{search} - R_{engage}}{v_{drone}}$$

### Firing Time per Drone

If we denote Where
$r_\text{fire}$ as the cannon's firing rate in rounds per second, and we
assume that each cannon engages $N_\text{drones} = 8$ drones simultaneously within a few seconds, the time to destroy $N_\text{drones}$ is:
$$t_\text{firing} = \frac{N_{rounds} - N_{drones}}{r_{fire}}$$

### Rounds Spent Per Target

On average, the system uses $N_\text{rounds} = 5$ rounds per drone, meaning
that for $N_\text{targets}$ drones, the total number of rounds spent is:
$$R_\text{total} = N_{rounds} * N_{targets}$$

### Drone Saturation

If $P_\text{saturation} > 1$, then the system is considered saturated (meaning drones will have successfully penetrated their targeted defence perimiter).

The system can handle $N_\text{radar}$ drones being tracked at once.
The probability $P_\text{{saturation}$ that the system becomes saturated dedepnds on the number of incoming drones:
$$P_\text{saturation} = \frac{N_{drones}}{N_{radar}}$$

### Cannon Rotation and Reaction Time

The system's reaction time matters. We'll denote it as
$t_\text{reaction}$, representing the time it takes for the cannon+radar system to
detect, prioritize, aim and fire at the next set of drones.
This variable can be approximated by a function of sensor processing speed `s_process` and mechanical movment (rotating the gun turret) `m_rotate`.
We assume the reaction time of the system is a constant `t_reaction` = 2 seconds. This gives us:
$$t_\text{reaction} = f(s_{process}, m_{rotate})$$

### Step 1: Clear the Scene!

Before we begin, we need to remove all objects that are created when we start Blender, usually it's a camera, a light, and a cube.

```python
import bpy

def clear_scene():
    # Clear existing objects in the scene
    bpy.ops.object.select_all(action='SELECT')
    bpy.ops.object.delete()
```

### Step 2: Create drones

Next we next drones. In our example we'll use a cube to represent each of our drones.

```python
def create_cube(name, location, scale=(1, 1, 1), color=(1, 1, 1, 1)):
    # Create a cube and set its location, scale, and color
    bpy.ops.mesh.primitive_cube_add(size=1, location=location)
    cube = bpy.context.active_object
    cube.name = name
    cube.scale = scale

    # Create a new material with the specified color
    mat = bpy.data.materials.new(name=f"{name}_Material")
    mat.diffuse_color = color
    cube.data.materials.append(mat)

    return cube
```

### Step 3: Set the scene

```python
def setup_scene(): # Set up the scene with a top-down orthographic camera and lighting
clear_scene()

    # Add a camera and set it to orthographic mode for a top-down view
    bpy.ops.object.camera_add(location=(0, -10, 10), rotation=(1.5708, 0, 0))
    cam = bpy.context.active_object
    cam.name = "TopDownCamera"
    cam.data.type = 'ORTHO'
    cam.data.ortho_scale = 20
    bpy.context.scene.camera = cam

    # Add a light
    bpy.ops.object.light_add(type='SUN', location=(0, 0, 10))
    light = bpy.context.active_object
    light.name = "SunLight"

    # Set the frame range for animation
    bpy.context.scene.frame_start = 0
    bpy.context.scene.frame_end = 100

```

def create_animation(obj, start_frame, end_frame, start_location, end_location):

    obj.location = start_location
    obj.keyframe_insert(data_path="location", frame=start_frame)

### Step 5: Execute!

```python
def main():
    setup_scene()

    # Create a tank (represented by a cube)
    tank = create_cube(name="Tank", location=(0, 0, 0), scale=(2, 2, 1), color=(0.2, 0.8, 0.2, 1))  # Green tank

    # Create drones (represented by smaller cubes)
    drone1 = create_cube(name="Drone1", location=(-5, 5, 1), scale=(1, 1, 0.5), color=(0.8, 0.2, 0.2, 1))  # Red drone
    drone2 = create_cube(name="Drone2", location=(0, 7, 1), scale=(1, 1, 0.5), color=(0.2, 0.2, 0.8, 1))  # Blue drone
    drone3 = create_cube(name="Drone3", location=(5, 5, 1), scale=(1, 1, 0.5), color=(0.8, 0.8, 0.2, 1))  # Yellow drone

    # Animate the drones moving towards the tank over 100 frames
    create_animation(drone1, start_frame=1, end_frame=100, start_location=(-5, 5, 1), end_location=(0, 0, 1))
    create_animation(drone2, start_frame=1, end_frame=100, start_location=(0, 7, 1), end_location=(0, 0, 1))

    # Set up rendering options

    bpy.context.scene.render.resolution_y = 1080
    bpy.context.scene.render.film_transparent = True

    # Render an animation to an output file
    bpy.context.scene.render.image_settings.file_format = 'FFMPEG'
    bpy.context.scene.render.filepath = "//anti_drone_animation"
    bpy.ops.render.render(animation=True)
