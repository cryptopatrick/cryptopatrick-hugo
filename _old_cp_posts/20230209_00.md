We start by installing ```opencv``` using our packagemanager **Homebrew**.
```bash
brew install opencv
```

Next we create the project and add the opencv crate.
```bash
cargo new --bin opencv_101
cargo add opencv
```

> We will need a working C++ compiler and libclang. We can meet this dependency by installing the OSX **Command Line Tools** (xcode-select --install) or **llvm** (using Brew). Be sure to check the opencv crates list of **Troubleshooting** tips.
