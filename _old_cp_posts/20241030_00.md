# What
To the previous code, please add a radar station, with a search radar covering a half-sphere dome with an outer range configurable to a 25 – 50 km instrumented range with 3 main operative modes:
– Combat (1.5 s/50°/35 km)
– Surveillance (3 s/25°/50 km)
– Sense and warn (1 s/70°/25 km) 
Also add a single unmanned aerial vehicle drone that will enter the airspace at a random time, fly around for 10 minutes and then leave the airspace. The Rust code should be able to simulate how the radar can detect the drone and create radar data that can be sent via a network.
Please use the Axum crate and also some way to print a regularly updated log to the command line regarding if the radar has identified a threat.

# Simulation
This radar simulation will have the following features:
+ Radar Station with adjustable range and modes (Combat, Surveillance, Sense and Warn).
+ A drone that enters and exits the radar's coverage randomly.
+ A network interface via Axum for sending radar data to a client.
+ An updated log that reports detections and threat status in real-time.

## Implementation Steps:
1. Define the radar parameters and modes.
2. Simulate drone entry and behavior.
3. Calculate radar detection based on the drone's position and radar mode.
4. Send radar data to clients via a network interface using Axum.
5. Log updates on detection status and threats.
