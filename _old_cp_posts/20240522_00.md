$$\\{F\\}=[K]\\{d\\} \tag{1}\label{eq1}$$



Equation $\eqref{eq1}$ is called the _Global Stiffness Equestion_ and is the
focus of this post.

Matrix notation represents a simple and easy-to-use notation for writing and 
solving _sets of simultaneous algebraic equations_.  
Let's break down the parts of $(1)$.


### Force Components Column Matrix, $\\{F\\}$
The subscript of $F_{\alpha \beta}$, identify the __node__ and the __direction of force__.  
For instance, $F_{1x}$ denotes the force at node $1$ applied in the $x$ direction.


### Global Stiffness Matrix, $[K]$
in _structural theory_, the elements $k_{ij}$ and $K_{ij}$ are referred to as 
_stiffness influence coefficients_

### Element Stiffness Matrix, $[k]$
For various types: bars, beams, trusses, plance stress, and 3D stress.
Also, procedure for for obtaining $[K]$, the global stiffness matrix for various structures.
How to solve $\\{F\\}=[K]\\{d\\}$ for unknown displacements in column matrix $\\{d\\}$.

### Nodal Points Column Matrix, $\\{d\\}$


> With practice, using matrix concepts and operations will become routine. We can use them to solve __small__ problems by hand, and to solve __large__ problems using digital computers.

A matrix is an $m \\, x \\, n$ array.
A column matrix has size of n x 1.

The { brace } notation can be used to denote a column matrix.  
The whole set of force values and the whole set of displacement values can thus be represented as  $\\{F\\}$ and $\\{d\\}$
The global nodal forces, $\{F\}$ and the golbal nodel displacements $\{d\}$
are related through the global stiffness matrix $[K]$, by:

$$\\{ F \\}=[K]\cdot \\{d\\} \right$$
