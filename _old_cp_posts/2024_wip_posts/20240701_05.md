# Steps
+ To test our `main.go` function we create `main_test.go`
+ We const two things, the name of the database driver (postgres)
  and the url to our dockerized database (we can get this from our Makefile) 
+ Using database/sql we Open the datbase by providing a dbdriver and a url to the database itself.
+ The `database,sql` library only provides a generic sql handler. We need to add
  database driver that is specific for Postgres. Go to:
  https://github.com/lib/pq  
  ...and run the following command in the terminal to install the Postgres driver:
  `$ go get github.com/lib/pq`
  This will also be added to our `./go.mod` file.

+ Go's `if err := nil ..` test format is kind of crude.  
  We can improve it by using:  
  visit https://github.com/stretchr/testify
  in terminal run:  
  `go get github.com/stretchr/testify`
  To import the package we have to import it:  
  // in account_test.go
  import "_ github.com/stretchr/testify/require"
+ We can now use testify's require object's methods:  
  NoError, NotEmpty, Equal.
+ Create a new database testobject using db.New() and passing the connection object.


# Docker Commands
+ Check which images are available locally. In terminal:  
  `docker images`
