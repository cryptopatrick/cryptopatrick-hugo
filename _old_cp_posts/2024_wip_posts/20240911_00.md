# Setup
We make sure to have `Node` and then install the bundler `vite`.
```bash
➜ node --version
v21.7.2
➜ npm --version
10.5.0
➜ npm create vite@4.1.0
```
We name our project `react-app`, choose React as our JS framework, and then choose TypeScript 
as our language.
Next we cd into our projects folder `cd react-app`, run `npm install` to install dependencies,
and finally run `npm run dev` to run our development server. Awesome, let's move on.
