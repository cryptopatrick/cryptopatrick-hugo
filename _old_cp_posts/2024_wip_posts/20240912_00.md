# The Generalized Model

For a top-down view, we start with:

1. a finite (or countable) set $V$
2. a random partition of $V$
3. a parameter $p \in [0,1]$

I always find it hard to think in abstract terms. Mathematics can often be translated into something concrete that is easier to grasp and reason about.
Let's do just that by translating these mathematical ideas into some crude source code and see what we get.

```rust
// 1. a finite (or countable) set $V$
// Use arrange like linspace to create random vecs?.
let v: Vec<f64> = vec![0;100.0];

// 2. a random partition of $V$
let partv: Vec<f64> = v.partition();

// 3. a parameter $p \in [0,1]$
let p: f64 = rand_inclusive(0,1,f64);
```

## Model

The corresponding `GDCM` is the $\\{0,1\\}$-valued process,
indexed by $V$, obtained by independently:

- for each partition element in the random partition chosen with probability $p$
- assign all the elements of the partition element, the value $1$.
- and with probability $1-p$ assign all the elements of the parttion element the value $0$.

## Definition and notation.

Let $V$ be a finite or countable set. Let $Part_V$ be the set of all partitions of $V$.  
Elements of $V$ will be referred to as vertices. Elements of a partition will be referred to as equivalence classes or clusters.

If $\pi \in \text{Part}_V$ and $v \in V$, we let $\pi (v)$ denote the partition element of $\pi$ containing $v$.  
For any `measurable space` $(S, \sigma (S))$, let $P(S)$ denote the set of probability measures on $(S, \sigma (S))$.

If $\pi \in \text{Part}_V$ and $K \subseteq V$, let $\pi _K$ denote the partition of $K$
`induced` from $\pi$ in the obvious way.  
On $\text{Part}_V$ we consider the $\sigma$-algebra $\sigma(\text{Part}_V)$ `generated` by $\\{ \pi _{K} \\} _{K \subset V,|K|< \infty}$.

# Questions studied in the paper

- Under what situations can different random partitions give rise to the same color process?
- What can one say concerning exchangeable random partitions?
- What is the set of product measures that color proceses stochastically dominates?
- For random partitions which are translation invariant, what ergodic properties do the resulting color process have?

# The motivation for studying these processes

1. The authors believe that this is 'a very natural and interesting class of processes'.
2. A number of well-studied examples of `color processes` belong to this class of process:

- The Ising Model
- The Fuzzy Potts Model
- The Voter Model
- Random Walk in Random Scenery
- Divide and Color Model
