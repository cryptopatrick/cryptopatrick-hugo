## Issueing Postgres commands from inside the docker container
In the postgres alpine container we have a 
postgres related cli that we can use to issue PG relaged commands.
So inside the container:
```shell
createdb --username=root --owner=root simple_bank
# to exit the shell, type:
exit
```


## Issueing Postgres commands from outside the docker container
```shell
docker exec -it postgres12 createdb --username=root --owner=root simple_bank
```

We can also access the database inside the container without going throug its shell:
```shell
docker exec -it postgres12 psql -U root simple_bank
```



This creates the database inside the container's postgres db.
we can now access the database psql with `psql``
We can also drop the database with: dropdb `simple_bank`

## migrate
https://github.com/golang-migrate/migrate

brew install golang-migrate

commands for migrate:
    // -ext is the extension of the file we're using
    // -dir is the directory where we want to store it
    // -seq will generate sequential migration files 1,2,3 up, and 3,2,1 down
    <name of migration>
    migrate create -ext sql -dir db/migration init_schema
    // run migration using the following command:
    // -path : where are the migrations located?
    // -database : which type of db are we changing? where is it? which port? 
    // what's its name? do we want migrate to logg what happens? do we want to migrate up or down?
    // we need to specify that our db does not (yet) have sslmode enabled.
    migrate -path db/migration -database "postgresql://root:secret@localhost:5432/simple_bank?sslmode=disable" -verbose up
    // Once we run this we can check the result in TablePlus. Rember that every time
    // we run a migration the version bumps +1 if we migrate up, and -1 if we migrate down
    up
    down
