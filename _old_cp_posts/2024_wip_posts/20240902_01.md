# Installation
We can install Triton using the Python installer `pip`.
Let's make sure we have pip installed and then use it to install the latest stable release of Triton:
```bash
$ pip --version
pip 24.2 from /usr/local/lib/python3.12/site-packages/pip (python 3.12)
pip install triton
```

> I'm on a Mac and use Homebrew for all my installations. will use `pipx`, a version of pip that can be installed using _Homebrew_. `pipx`  will manage a
    virtual environment for me.
    
The command for that is:

```bash
$ brew install pipx
```
