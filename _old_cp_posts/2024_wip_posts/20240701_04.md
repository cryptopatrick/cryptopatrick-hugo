# Steps
+ Understand the pro/cons of ____database/sql____, ____gorm____, ____sqlx____, and ____sqlc____  
  Bottomline: __sqlc__ provides compiletime checks
+ Remember: it's available for Postgres, Mysql, and SQLite  
+ Install __sqlc__ by going to [sqlc.dev](https://sqlc.dev) and run:  
  `brew install sqlc`
+ Verify installation:  
  `sqlc version`
+ Go to your project folder's root, "./simplebank" and create a sqlc settings file:
  `sqlc init`  
+ Open the settings file in VS Code
  `code .`
+ Indicate to sqlc where it can find the database's queries.
  Create the following two folders:  
  `mkdir ./db/sqlc` 
  `mkdir ./db/query` 
+ Open the documentation of sqlc for the version that you are using, for example 1.26:
  `open https://docs.sqlc.dev/en/v1.26.0/tutorials/getting-started-postgresql.html`
+ Change the settings:

```bash
  version: "1"
  packages:
  - name: "db"
    path: "./db/sqlc"
    queries: "./db/query/"
    schema: "./db/migration/"
    engine: "postgresql"
    emit_json_tags: true
    emit_prepared_queries: false
    emit_interface: false
    emit_exact_table_names: false
```
+ Add the migrations command to the `./Makefile`.  
  Remember to add `sqlc` to the `.PHONY` list in the Makefile:  
  `sqlc:  
    sqlc generate`    
  `.PHONY: sqlc`
+ Create the file `.db/query/account.sql`
+ Look at the [sqlc docs](https://docs.sqlc.dev/en/v1.26.0/tutorials/getting-started-postgresql.html#schema-and-queries) to see how querries should look:

```bash
This:
CREATE TABLE "accounts" (
  "id" bigserial PRIMARY KEY, // automatically incremented
  "owner" varchar NOT NULL,
  "balance" bigint NOT NULL,
  "currency" varchar NOT NULL,
  "created_at" timestamptz NOT NULL DEFAULT (now()) // automatically set
);

Would CRUD into this:
INSERT INTO accounts (
  owner, 
  balance, 
  currency
) VALUES (
  $1, $2, $3 // for owner, balance, currency
) RETURNING *;

-- name: GetAccount :one
SELECT * FROM accounts
WHERE id = $1 LIMIT 1;

-- name: ListAccounts :many
SELECT * FROM accounts
ORDER BY id
LIMIT $1
OFFSET $2;

-- name: UpdateAccount :one
UPDATE accounts
  set balance = $2
WHERE id = $1
RETURNING *;

-- name: DeleteAccount :exec
DELETE FROM accounts
WHERE id = $1;
```

+ Remember, we only need to provide arguments for variables that will _not_ be autogenerated by sql.
  For example, the primary key _id_ is an autoincrimented value, so we don't need add it.
  Also, date is not something we need to add.
+ Add the sql querries, based on the format in the docs, and your domain, to:  
`.db/querries/accounts.sql` 

> Important: once the account is created, we will want to return it's id to the client. 



---

# Key __sqlc__ Commands
+ Check that the sql is correct:  
  `sqlc compile`
+ Check that the sql is correct _and_ generate the migrations:  
  `sqlc generate`
+ Create and empty _sqlc settings yaml_ file:  
  `sqlc init`
