## 1. Initiate the project
```bash
# Commandline
cargo new webserver
cd webserver
# Edit Cargo.toml from the cmdline:
cargo add axum, tokio
```

## 2. Create the server
```rust
// file: src/main.src
use axum::{routing::get, Router};
use std::net::SocketAddr;
use tokio::net::TcpListener;

// Function we'll call as our first route handler.
async fn ping() -> &'static str {
  "ping"
}

#[tokio::main]
async fn main() {
  let router = Router::new()
    .route("/", get(ping))
    .route("/hello", get(return_a_struct_as_json));
  
  let listener = tokio::net::TcpListener::bind("127.0.0.1:8000").await.unwrap();
  
  axum::serve(listener,router).await.unwrap();
}
```

# Extractors
Extractors are arguments that can be passed to handlers. 

```rust
async fn function_with_extractors(
  Json(json): Json<MyStruct>) -> impl IntoResponse {
    format!("Contents of my_field: {}", json.my_field)
  }
```
