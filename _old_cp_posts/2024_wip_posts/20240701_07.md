# Steps
+ Install `Docker Desktop` for MacOs
+ Go to  `www.dockerhub.com` and search for `Postgres` image
+ Download the container image. In terminal do:  
  `docker pull postgres:12-alpine`
+ Run the image. In terminal do:  
  `docker run --name postgres12 -e POSTGRES_USER=root -e POSTGRES_PASS=secret -p 5432:5432`
+ Execute a command inside the container:  
  `docker exec -it <container_id> <command> [args]`  
  `docker exec -it postgres12 psql /bin/sh`
+ In VS Code, open the `database.sql` file created with dbdiagram.io:
+ Select all the contents of the database.sql file
+ Download `TablePlus` from www.tableplus.com  
+ 

# Docker Commands
+ Check which images are available locally. In terminal:  
  `docker images`
+ Start a container based on an image:  
  `docker start <imagesname> //postgres12`
+ Stop a container based on an image:  
  `docker stop <imagesname> //postgres12`
+ List available containers, both started and stopped?:  
  `docker ps`
+ Which containers are currently stopped?:
  `docker ps -a`
