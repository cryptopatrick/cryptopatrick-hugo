## Step 2.0: Connect to the Database from Rust
+ add .env file to root of cargo/forum project.
+ in the .env file add path variable to postgres db
  ```DATABASE_URL=postgresql://postgres:mysecretpassword@localhost:5432/forum```
+ To read the path variable from Rust we need to add a crate called `dotenvy` 
+ https://crates.io/crates/dotenvy
```shell
cargo add dotenvy
```

  > The original dotenv crate is no longer maintained.

We can now connect to our database from main.rs, using:
```scala
use std::env;
use dotenvy::dotenv;

fn main(){
  dotenv().ok();
  let database_url = env::var("DATABASE_URL").expect("Connection Failed");
  println!("{}", database_url);
}
```

## Step 03: Init Axum
In this step we start building a very simple version of our server.
We need to add two things: 1) a route and 2) a listener that handles requests.
```scala
use std::env;
use dotenvy::dotenv;
// We add the dependencies of Axum
use axum::{
  routing::get,
  Router
};

#[tokio::main]
async fn main(){
  dotenv().ok();
  let database_url = env::var("DATABASE_URL").expect("Connection Failed");
  println!("{}", database_url);

  let pool = sqlx::postgres::PgPoolOptions::new()
      .max_connections(10)
      .connect(&database_url)
      .await
      .expect("Failed to connect to database");



      //  let pool = sqlx::PgPool::connect(&database_url)
      //.max_connections(10)
      //.await
      //.expect("Failed to connect to database");

            // build our application with a single route
        let app = Router::new().route("/", get(|| async { "Hello, World!" }));

        // run our app with hyper, listening globally on port 3000
        let listener = tokio::net::TcpListener::bind("0.0.0.0:300")
            .await
            .unwrap();
        
      println!("{}", database_url);

    // Serve
    axum::serve(listener, app).await.unwrap();

}
```

We can now run our server and visit localhost:3000 to see our server running.
```shell
cargo run &
open -a Safari localhost:3000 &
```

## Step: Add the PgPool to our global state
```scala
//We clone this becase we might need multiple versions of the pgpool.
#[derive(Clone)]
struct AppState {
    pool: PgPool,
}
```

We can then use this to initialize an app state that we'll use.
```scala
let app_state = AppState{pool: pool};
```
Next, we connect our Axum `app` with our `app_state`.
```scala
    let app = Router::new()
      .route("/", get(|| async { "Hello, World!" }))
      .with_state(app_state);
```


Since we will be adding many routes it's easiest to have the routes in a separate file.
