Agent Claude: Read/Write Permission to our local Repo
Agent Code: Read/Write Permission to our local Repo
Communicate: Claude 

Great — here’s a clean macOS recipe to make Agent Y writable and Agent X read-only on the same machine.

Option A — Group-based (simple, good for “some can write, others read”)

1) Create a writers group and add Agent Claude

```bash
# create a local group named "gitwriters"
sudo dseditgroup -o create -r "Git Writers" gitwriters
# add Agent Y (replace 'agenty' with their macOS short name)
sudo dseditgroup -o edit -a agenty -t user gitwriters
```
2) Create a shared location and init a bare repo
```bash
sudo mkdir -p /Users/Shared/git
cd /Users/Shared/git
sudo git init --bare project.git --shared=group
```
3) Set ownership and permissions

```bash
# hand group ownership to gitwriters
sudo chgrp -R gitwriters /Users/Shared/git/project.git

# writers (group) get rw; everyone else gets read/execute only
sudo chmod -R g+rwX,o+rX /Users/Shared/git/project.git

# keep new directories/files in the writers group (setgid on dirs)
sudo find /Users/Shared/git/project.git -type d -exec chmod g+s {} \;
```

4) Set a friendly umask for writers (so new files are group-writable). 

```bash
#Ask each writer (Agent Y) to add to ~/.zprofile:
umask 002
```

Then have them open a new terminal.
Usage

Agent Y (in gitwriters) can push:
```bash
git clone /Users/Shared/git/project.git
# work, commit
git push
```
Agent X (not in gitwriters) can clone/pull but will get “permission denied” when pushing.
