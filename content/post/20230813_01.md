# Parts (is part of...)
Parts are object in the database. We can think of them as 
_relationships_ between items of _different_ type.

A part is _owned_ (defined) by an item.
The relationships are part of the meta model of the sw db.

A part always has a _part type_.
We can get all the general properties of a particualr part.

items
  VolvoXC60 (Item type: car)
  Forgeline (Item type: wheel)
parts
  FrontRight (is part of VolvoXC60)
  FrontLeft
  RearRight
  RearLeft

If we select an item and try to link that item to another item, using a part (relationship), we will be limited by the
meta model in terms of which part type (relationship type)
that can be added to the item.

# SID
SystemWeaver IDentifier is the formal identification of a type in SW. Is 1 to 8 Unicode character string value
used internally to track the types of items, parts, and attributes - and the internal relationships between different types.

Each SID is unique in the SW db.

SIDs are used to refer to a specific type - for example 
in a report. The SID is the actuall _key_ of a type, 
not its name - so the name can always be changed
without breaking the model.
