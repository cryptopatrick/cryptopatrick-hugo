__Definition 1.1.__ A collection of $A$ of subsets of a set $X$ is an $\mathbf{\text{algebra of sets}}$  
if it satisfies the following axioms:  
+ (a)  The _whole_ set $X$ and the empty set $\emptyset$ belong to $A$.
+ (b)  The _complement_ $X\setminus E$ of a set $E$  in $A$ belongs to $A$. (closed under complements)
+ (c)  The _union_ of a finite collection of sets in $A$ belongs to $A$.

__Set $X$__  
Let's have $X$ represent all the soldiers and officers stationed at a military base. Each  
$$X = \\{S1, S2, S3, S4, S5 \\}$$

Next, we divide all the soldiers up in teams and officers (subsets):
+ Alpha team: $A = \\{S1, S2 \\}$
+ Bravo team: $B = \\{S3, S4 \\}$
+ Officers: $C = \\{S5 \\}$

__Subsets of $X$__  
We can _combine_ our subsets in different ways, including no subsets. This set of combinations is denoted the _algebra of A_, of the set $X$:

```rust
// Below is A, our collection of subsets E1, E2, ..., of the set X.
∅, // No one on base
{S1, S2}, // Alpha team
{S3, S4}, // Bravo team
{S5}, // Officers
{S1, S2, S3, S4},  // Soldiers only
{S1, S2, S5}, // Alpha team plus Officers
{S3, S4, S5}, // Bravo team plus Officers
X = {S1, S2, S3, S4, S5} // Everyone on base
```

> So, the intuition in our example is that our algebra $A$ denotes all the _permissable groupings_ (unions) of _subsets_ in the set $X$, expressing the concepts: _no one_, _everyone_, _opposites_, and _combinations_.

## Check: is $A$ an algebra?  
Now, in order for our collection $A$ to be _algebra_, it needs to meet the axioms, declared in __Definition 1.1.__. Do they? Let's see. 
+ Axiom (a): The whole set $X$ and the empty set $\emptyset$ belong to $A$
```rust
X = {S1, S2, S3, S4, S5} // Everyone on base
∅, // No one on base

✅ Axiom (a) is satisfied
```

+ Axiom (b): The complement $X \setminus E$ in $A$ belongs to $A$
We need to check if the complement of each subset is in $A$ is also an element in $A$. Checking this entails taking the complement of each subset and checking that that set is an element in $A$:
```rust
// The complement of Alpha team...
{S3, S4, S5} 
// ...is the same as...
{S3, S4, S5}, // Bravo team plus Officers

// We need to do this check for every subset in $A$.
// which will show that the axiom is met.
✅ Axiom (b) is satisfied
```


+ Axiom (c): The union of a finite collection of sets in $A$ belongs to $A$
If we combine subsets then we should find the result of that combination as a subset in $A$:

```rust
// All soldiers
Alpha U Bravo = {S1, S2} U {S3, S4} = {S1, S2, S3, S4} 
// Alpha team plus officers
Alpha U Officers = {S1, S2} U {S5} = {S1, S2, S5} 
// Bravo team plus officers
Bravo U Officers = {S3, S4} U {S5} = {S3, S4, S5} 

✅ Axiom (c) is satisfied
```

As we can see, all the axioms of definition 1.1. are met, and 
we are therefore allowed to denote our collection $A$ an __algebra of sets__.  

## Extending $A$ into a Sigma-Algebra or Borel Field
Having covered the baseline, we are now in position to extend these concepts into a more powerful structure:
the __sigma-algebra__, adding one additiona superpower:
we are now allowed to take _countably infinite unions_ of sets in the collection.

So basically, instead of a set $X$ of _fixed_ size, we can now handle sets that can change in size dynamically:
$$X = \\{S1, S2, S3, S4, S5, \dots \\}$$

Next, we add some kind of __measure__, for example, let's say we want to __tag__ (measure) which soliders that are part of our military base, that are currently either:
+ Fighting in the Northern sector, $A_N$
+ Fighting in the Western sector, $A_W$
+ Stationed on base, $A_B$

So the sigma-algebra $A$ represents all the soldiers/officers of our military base, that are "measurable" - meaning, wholse behaviour we can track/logg/reason about.

What new is that now we can keep tagging (updating) as things change. A unit might go from fighting in the Northern sector, to returning to the military base, $A_N \rightarrow A_B$.
Our sigma-algebra ensures that even after thousands of hours of logging, no soldier will be logged in two states simultaneously, 
like S1 is both fighting in the Northern sector, $A_N$, while also  chillin' back at the military base, $A_B$.
$$A_N \cup A_W \cup A_B \cdots$$

> So the point is that our __algebra of sets__ can only handle finite unions of sets, while our sigma-algebra can handle growing and even infinite sets. Which is useful for ongoing events, like $S1$ moving from fighting in the northern sector and returning back to base. We can also use them to hanble continous time, rather than discreet time.

## Entering _Measuable Space_
By a measurable space we mean a pair $(X,\mathcal{X})$ consisting of an arbitrary set $X$
and a $\sigma \mathit{-algebra} \\;\mathcal{X}$  of subsets of $X$. Sets in $\mathcal{X}$ are called __measurable sets__ (with respect to the $\sigma \mathit{-algebra} \\; \mathcal{X}$)
or $\mathcal{X} \mathit{\text{-measurable sets}}$.
