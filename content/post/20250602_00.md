> concepts to define: Differentiability, Smoothness, Jacobian Matrix

Let $p=(p^1, \dots, p^n)$ be a _point_ in an _open set_ $U \in \mathbf{R^n}$.
Let's denote $k\in \mathbf{Z_+}$ to represent the _order_ of derivates that we are talking about.
We now declare $f: \mathbf{U} \rightarrow \mathbf{R}$ to denote a function which maps values from $U$ to a _real-valued_ output from $\mathbf{R^n}$.  
{{<indentline>}}The function $f$ is said to be $C^k$ at point $p\in U$, if the following conditions apply:  
+ all _partial derivatives_  of $f$ are of order $j \le k$, meaning that the function is differentiable up to the $k$th order  
+ these _partial derivatives_ are _continuous_ at point $p$, which means they behave nicely (they don't jump around, break, or behave erractically like a Weierstrasse function)


The function $f:U \rightarrow \mathbf{R}$ is said to be $C^\infty$ at point $p$, if it is $C^k$ for all $k\ge 0$.  
In other words, its partial derivates

$$\frac{\partial^jf}{\partial {x^{i_1}}, \cdots, \partial{x^{i_j}} }$$

of all orders, _exist_ and are _continuous_ at $p$.  
{{<indentline>}}A vector-valued function $f: U \rightarrow \mathbf{R^m}$ is said to be $C^k$ at point $p$ if all its _component functions_ $f^1, \cdots, f^m$ are $C^k$ at $p$.  
A similar definition holds for a $C^\infty$ function on an open set $U$.

{{<indentline>}}We say that $f: U \rightarrow \mathbf{R^m}$ at $p$ is $C^k$ on $U$ if it is $C^k$ at every point in $U$. 

> We treat the terms $C^\infty$ and "smooth" as synonyms.
