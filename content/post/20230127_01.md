# Motivationssss
**Number Theory** is one of the oldest branches of mathematics. It is used to **study the properties of integers**. At the heart of Number Theory we find the concept of **divisibility** and the problem of finding out *if a given integer* $m$ *is divisible with the integer* $n$. Applications of Number Theory range from cryptography, device authentication, websites for e-commerce, coding, security systems, and many more.

## 1.1 Definition: Divisibility
Let $\lambda$ and $\varphi$ be integers. 
We say that $\lambda$ **divides** $\varphi$, and write this as $\lambda \vert \varphi$, if there exists an integer $\eta$ such that $\varphi = \eta \cdot \lambda$. What we're saying is that $\varphi$ is a **multiple** of $\lambda$. In mathematics we can formalize this idea succinctly by writing:

$$\lambda, \varphi, \eta \in \mathbb{Z}:\lambda \vert \varphi \iff \varphi = \eta \cdot \lambda$$

> **Example**: The integer $4$ is a divisor of the integer $12$, since there is an integer $3$ such that $12=3\cdot 4$. Further, $-20$ is a divisor of $100$ since there is an integer $-5$ such that $100=-5\cdot -20$.

Let's write a simple function to express the concept of divisibility in code:

```scala
fn is_divisor<T>(lambda:T, phi:T, eta:T) -> bool 
// We use a trait bound to limit arguments to types that implement the Ord trait.
where
    T: Ord + std::ops::Mul<Output = T>  
{
        return phi == eta * lambda;
}
  
  #[test]
  fn test_is_divisor_for_int() {
    assert_eq!(is_divisor(4,12,3), true);
    assert_eq!(is_divisor(-5,100,4), false);
    assert_eq!(is_divisor(-5,100,-20), true);
  }
```

## 1.6 Definition: Greatest Common Divison (GCD) 
If $\lambda, \varphi$, and $\eta$ are integers we say that $\eta$ is a **common divisor** of $\lambda$ and $\varphi$, if $\eta \vert \lambda$ and $\eta \vert \varphi$.
The **greatest common divisor** of $\lambda$ and $\varphi$ is the greatest integer $\eta$ in the set of common divisors of $\lambda$ and $\varphi$.
We write this as $\eta = gcd (\lambda, \varphi)$.

> The positive divisors of 45 is the set $A = \\{1,3, 5, 9, 15, 45\\}$ and of 75 it is the set $B = \\{1,3,5,15,25,75\\}$ . The **highest number** in $A \cap B = \\{1,3,5,15\\}$ is 15.  
So the gcd(45,75)=15.
