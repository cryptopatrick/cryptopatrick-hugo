### Document Processing
Although there are severatl tools that we can use to extract data from documents, one challenge is to find
a universal solution that works well for _all_ kinds of data.

Solution chosen: transition from pdfs to google docs, using html formatting for more accurate text
extraction. We'll use __MarkitDown__ to load the data in Markdown (PDF-MD).
Four candidates: LlamaParse, Pypdfium2, Unstructured Loader, Docling, 

> arxig.org/pdf/2410.09871 A comparative study of pdf parsing tools across diverse document categories showed wthat PyPDFium works very well across different categories (financial, scientific, etc)
