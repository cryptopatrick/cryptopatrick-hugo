Model Context Protocol (MCP) is a standardized way to connect LLMs and Artificial Intelligence Agents to outside sources.

### Web APIs
There are thousands of popular web APIs that we can connect to using MCP, for example: Google Maps API, Twitter API, OpenWeatherMap API, Star Wars API (https://swapi.dev), or Pokémon API (https://pokeapi.co).

### Datasources

### Local File System

The _MCP Server_ wraps the above mentioned sources as _MCP Tools_, and makes them available to the MCP client.


## MCP Client
An Ai application can use the MCP client to communicate with the 
MCP Server. These MCP Clients are wrapped inside _MCP Hosts_, like for example: _Claude Desktop_ and _Cursor IDE_.

🧪 These MCP Hosts typically sends our prompt "Which city is currently warmest, Paris, New York, or Beijin?", external LLM (calling an API).

> But wait, what if our company has proprietary data which cannot be shared with an outside vendor, and we want to use MCP to make it available as an MCP Tool to our Ai application?

Our solution needs to be 100% local, in that it does not send a single bit of proprietary data to an external vendor, while still allowing us to create a nice ChaptGPT-like user interface with which to interact with our data.

So, we need to build our own MCP Client that can connect to any MCP Server on the Internet.
